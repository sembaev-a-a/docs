## Улучшения

### Улучшено взаимодействие "Настройка действий"
Все действия теперь отображаются в едином выпадающем списке без разделения на "Включить действия" и "Настроить".
- Действия, которые можно добавить только один раз: сохраняется эффект переключателя.
- Действия, которые можно добавлять многократно: теперь не используют переключатели и могут добавляться несколько раз.
- Объединены похожие действия:
  - “Добавить новое” и “Добавить запись”
  - “Отправить” и “Сохранить запись”
![20240520153033](https://static-docs.nocobase.com/20240520153033.png)

### Унифицирован формат данных результатов HTTP-узла рабочего процесса:

```js
{
  config: {},
  headers: {},
  status: 500,
  statusText: 'xxx',
  data: {}
}
```

## Исправления

### Плагин логов теперь отображает только логи текущего приложения
При наличии нескольких приложений:
- Плагин логов отображает только список файлов логов текущего приложения.
- Папки рабочих процессов и пользовательских запросов размещены внутри папки приложения.
![20240520152448](https://static-docs.nocobase.com/20240520152448.png)

### Другие важные исправления:
- Диаграммы не преобразовывали поля даты к локальной временной зоне клиента при агрегации по дате. <a href="https://github.com/nocobase/nocobase/pull/4366" target="_blank">fix(data-vi): should use local timezone when formatting date #4366</a>
- Проблема с обновлением представлений, когда требовалось выйти и заново войти после синхронизации с базой. <a href="https://github.com/nocobase/nocobase/pull/4224" target="_blank">fix: collection fields should be refreshed after editing sync from database #4224</a>
- В блочном дереве таблицы не происходило скрытие всех узлов при добавлении дочернего узла. <a href="https://github.com/nocobase/nocobase/pull/4289" target="_blank">fix: do not collapse all nodes when adding a child node in the tree table block #4289</a>
- Настройки заголовочного поля таблицы данных не применялись. <a href="https://github.com/nocobase/nocobase/pull/4358" target="_blank">fix: collection title field setting is invalid #4358</a>
- Поле Bigint теряло точность в режиме только для чтения. <a href="https://github.com/nocobase/nocobase/pull/4360" target="_blank">fix: bigint field loses precision in read pretty mode #4360</a>
- Открытые лог-файлы не закрывались после остановки подприложения. <a href="https://github.com/nocobase/nocobase/pull/4380" target="_blank">fix(logger): should close log stream after destroying app #4380</a>
- Баг выбора модели данных связей в агрегационном узле рабочего процесса. <a href="https://github.com/nocobase/nocobase/pull/4315" target="_blank">fix(plugin-workflow-aggregate): fix association field select #4315</a>
- Опция игнорирования ошибок не работала в синхронном режиме для HTTP-узла рабочего процесса. <a href="https://github.com/nocobase/nocobase/pull/4334" target="_blank">fix(plugin-workflow-request): fix ignoreFail in sync mode #4334</a>

- Исправлена проблема, когда настройка marginBlock в редакторе темы сказывалась на интервале между полями формы. <a href="https://github.com/nocobase/nocobase/pull/4374" target="_blank">fix(theme-editor): form field spacing should not be affected by token.marginBlock #4374</a>
