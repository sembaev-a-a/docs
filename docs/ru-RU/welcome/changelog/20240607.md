### Блоки поддерживают настройку высоты ([#4441](https://github.com/nocobase/nocobase/pull/4441))

## Улучшения

### Оптимизация импорта и экспорта ([#4468](https://github.com/nocobase/nocobase/pull/4468))
Улучшена стабильность и расширен лимит импорта/экспорта до 2000 записей. Поддерживается расширенная логика для пользовательских типов.
![20240611112948](https://static-docs.nocobase.com/20240611112948.png)

### Избежание ошибочных действий при выборе переменной даты ([#4452](https://github.com/nocobase/nocobase/pull/4452))
Все переменные-даты теперь интервал (массив), а не строка — подходят для фильтрации, но не как значение по умолчанию.
![20240527150429](https://static-docs.nocobase.com/20240527150429.png)

### Улучшение взаимодействия правила связи ([#4492](https://github.com/nocobase/nocobase/pull/4492))
Убрана возможность назначения опций для полей с множественным выбором. При переключении типа поля настройки очищаются.
![20240603143309](https://static-docs.nocobase.com/20240603143309.png)

### Правка иконки действий в таблице ([#4538](https://github.com/nocobase/nocobase/pull/4538))
Изменилась иконка в столбце действий блока таблицы.
![20240603115131](https://static-docs.nocobase.com/20240603115131.png)

### Обработка ошибок ([#4459](https://github.com/nocobase/nocobase/pull/4459))
Более гибкая обработка ошибок разных компонентов: страница не «падает» полностью при ошибке фронта.
![error-fallback](https://static-docs.nocobase.com/20240604122043_rec_.gif)

### Быстрый сбор логов при ошибках на клиенте ([#4524](https://github.com/nocobase/nocobase/pull/4524))
Реализована удобная загрузка логов для отладки при возникновении ошибки.
![error-fallback-log](https://static-docs.nocobase.com/202406041224009.png)

### Прочие улучшения
- Длина имени пользователя ограничена 1-50 символами ([#4502](https://github.com/nocobase/nocobase/pull/4502))
- Не скрывать поля внешних ключей ([#4499](https://github.com/nocobase/nocobase/pull/4499))
