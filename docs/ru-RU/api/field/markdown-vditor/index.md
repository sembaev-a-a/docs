# Markdown

**Markdown** — это облегченный язык разметки, который позволяет форматировать текст с помощью простых символов. 

### Основные возможности Markdown:

#### 1. Заголовки
```markdown
# Заголовок 1 уровня
## Заголовок 2 уровня
### Заголовок 3 уровня
```

#### 2. Текст
```markdown
*курсив* или _курсив_
**жирный** или __жирный__
~~зачёркнутый~~
```

#### 3. Списки
```markdown
- Неупорядоченный список
1. Упорядоченный список
- [ ] Чек-лист
- [x] Выполненный пункт
```

#### 4. Ссылки и изображения
```markdown
[Текст ссылки](https://example.com)
![Альтернативный текст](image.jpg)
```

#### 5. Код
````markdown
`Встроенный код`
```javascript
// Блок кода
console.log("Hello World");
```
````

#### 6. Цитаты
```markdown
> Это цитата
>> Вложенная цитата
```

#### 7. Таблицы
```markdown
| Заголовок 1 | Заголовок 2 |
|-------------|-------------|
| Ячейка 1    | Ячейка 2    |
| Ячейка 3    | Ячейка 4    |
```
